# LIGGGHTS Windows Prebuilt Release

This repository contains the corresponding source code for an unofficial
prebuilt Windows x64 release of LIGGGHTS-PUBLIC.

## Download

Download the latest release from the Releases page.

## Prerequisites

Before running `liggghts.exe`, install:

1. Microsoft Visual C++ Redistributable (included in zip)
2. Microsoft MPI (included in zip)

Both installers are in the `prerequisites/` folder of the release zip.
